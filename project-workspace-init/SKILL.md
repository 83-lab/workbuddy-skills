# project-workspace-init

## 激活机制

WorkBuddy 的 Skill 没有系统级钩子，必须主动调用才能生效。
**每次用户给任务时，AI 先调用 `Skill("project-workspace-init")`再开始工作**——这是唯一触发入口。

已初始化过的工作空间，阶段三跳过，无任何多余开销。

### 执行流程

```
用户给任务
  ↓
阶段一：经验库检索（每次任务前必做）
  ├── 顺带检查工作空间是否已初始化
  │   ├── 未初始化 → 阶段三：创建目录结构 + 写入 MEMORY.md
  │   └── 已初始化 → 跳过（无感）
  └── 匹配经验文件并读取 → 指导本次任务
  ↓
阶段二：Prompt 模板匹配（prompt/ 目录存在时执行）
  ↓
正常执行任务
  ↓
阶段四：整理产出物到 outbox/（每次任务后必做）
阶段五：复杂任务归纳经验（仅 8+ 工具调用时触发）
```

---

## 阶段一：经验库检索 + 工作空间惰性初始化检查（每次任务前）

在正式执行任何任务前：

### 第一步：检查当前工作空间是否已初始化
- 检查当前 workspace 根目录下是否存在 `inbox/` 目录
- **存在** → 已初始化，跳过（无感，不告知）
- **不存在** → 首次使用，按阶段三初始化（仅一次）

### 第二步：搜索经验库
检查 `D:\经验库\` 目录：
1. 检查 `D:\经验库\` 是否存在
2. 如存在，扫描该目录下所有 `.md` 文件
3. 根据当前任务的关键词匹配文件名和内容
4. 匹配规则同 Prompt 匹配（见下方表格）
5. **有匹配** → 先读取相关经验文件，了解已有经验后再执行任务
6. **无匹配** → 跳过，正常处理

> 经验文件来自本 skill 的阶段五产出，以及谋而后动 skill 的产出，包含复杂任务的解决过程、避坑要点、模板等。

---

## 阶段二：Prompt 模板自动匹配复用（每次任务前）

当用户在当前项目 workspace 中给出任何任务时，自动执行：

### 第一步：检测 prompt 目录
- 检查当前 workspace 根目录下是否存在 `prompt/` 文件夹
- 如不存在，跳过此流程

### 第二步：扫描模板文件
- 读取 `prompt/` 目录下所有 `.md` 文件
- 每个文件 = 一个指令模板
- 从文件名和文件内容中提取关键词（任务类型、输出格式、适用场景）

### 第三步：按任务类型自动匹配

根据用户当前请求的任务类型，匹配最合适的模板：

| 用户输入关键词 | 匹配模板关键词 |
|--------------|--------------|
| OCR、截图提取、文字识别、提取文字 | OCR、截图、识别、提取 |
| 翻译、中英、translate | 翻译、translate、中英 |
| 报告、周报、总结、纪要 | 报告、周报、总结、纪要 |
| 评分、分类、去重 | 评分、分类、去重 |
| 验证、GMP、SOP | 验证、GMP、SOP、确认 |
| （扩展）从经验库文件名关键词 | 自动扩展 |

匹配规则：
- **唯一匹配** → 自动读取并执行，告知用户"自动应用了xxx模板"
- **多个匹配** → 按文件名序号或文件修改时间选优先级最高的 1 个，告知用户"自动应用了xxx模板"
- **无匹配** → 正常处理，并告知用户"未找到匹配的指令模板，如有常用指令建议保存到 prompt/ 文件夹"

### 第四步：执行任务
- 读取匹配的模板内容
- 严格按模板中的指令执行任务
- 任务结束后，结果自动保存到 outbox/ 对应子目录（见阶段四）
- 文件名使用 `YYYY-MM-DD-任务描述-v1` 格式

---

## 阶段三：工作空间初始化（新建项目时触发）

当发现用户在一个全新的项目工作空间中（尚未初始化过），自动执行：

1. **检测当前 workspace 根目录**
2. **检查是否已存在 inbox/outbox/archive/prompt 结构**
3. **如不存在，自动创建目录树：**

```
项目根目录/
├── inbox/              ← 原始材料入口（截图、PDF、数据文件等）
│   ├── 01-待整理数据/   ← 原始数据/Excel/CSV
│   └── 02-待总结文档/   ← Word/PDF/截图待提取
├── outbox/             ← AI 结果出口（仅存放待检查的初稿）
│   ├── Word报告/
│   ├── 表格结果/
│   └── 其他输出/
├── archive/            ← 已完成任务归档
│   └── 已完成任务/     ← 按 日期-任务名称 建子文件夹
└── prompt/             ← 指令模板库（可复用 .md 文件）
    └── README.md       ← 说明怎样添加新模板
```

4. **将文件组织规范写入项目 MEMORY.md**：在项目 `.workbuddy/memory/MEMORY.md` 中追加（或创建）"工作空间文件组织规范"章节，包含产出物存放规则、原始材料规则、经验库规则
5. **告知用户结构已创建**，并简要说明各文件夹用途及 MEMORY.md 已写入规范

## 阶段四：任务后自动整理产出物（每次任务后）

**任务完成后自动执行，不需要用户提醒。**

### 检查清单
1. 本次任务产出了哪些文件（docx/xlsx/pdf/png/html 等）
2. 这些文件当前在什么路径
3. 按类型分类移动到 outbox/ 对应子目录
4. 如果文件在项目根目录，**必须移走**（根目录只留脚本/配置）

### 移动规则

| 文件类型 | 目标目录 |
|---------|---------|
| .docx 报告类 | `outbox/Word报告/` |
| .xlsx 表格类 | `outbox/表格结果/` |
| .pptx 演示类 | `outbox/其他输出/` |
| .pdf 文档类 | `outbox/其他输出/` |
| .png/.jpg 截图类 | `outbox/其他输出/` |
| .html 网页类 | `outbox/其他输出/` |
| .md 文档类 | `outbox/其他输出/` |
| 其他交付物 | `outbox/其他输出/` |

### 文件名规范
- 使用 `YYYY-MM-DD-任务描述-v序号` 格式
- 禁止使用"最终版""新版""定稿"等模糊命名
- 如果已有同名文件，检查内容差异，确认后覆盖或升版本号

### 告知用户
一句话说明："产出物已整理到 outbox/xxx/，请人工确认后移入 archive/"

## 阶段五：复杂任务经验自动归纳（每次任务后）

**仅在复杂任务（8+次工具调用 或 明显需要复用的场景）后触发。**

### 触发条件
- 本次任务使用了 8 次以上工具调用
- 任务涉及：文档生成、数据处理、脚本编写、系统配置、流程搭建
- 任务有明显可复用的模式、代码、或避坑点
- 任务解决了之前未遇到过的问题

### 执行步骤

1. **检查 `D:\经验库\` 是否存在**，不存在则创建
2. **检查是否已有同类经验**：按任务类型关键词匹配已有文件
3. **生成经验文件**（`.md` 格式），包含：

```markdown
# 经验：{任务简述}

## 场景
什么项目、什么需求、什么背景

## 问题描述
一开始遇到了什么问题

## 解决过程
关键步骤、技术选型、踩坑记录

## 关键代码/配置
可复用的核心片段（代码块）

## 避坑要点
最容易翻车的点

## 可复用模板/清单
下次做类似任务可以直接用的检查清单或模板

## 相关文件
outbox 中的产出文件路径
```

4. **保存到** `D:\经验库\{YYYY-MM-DD-任务简述}.md`
5. **更新经验库索引**（追加到 `D:\经验库\README.md` 的索引区）

### 告知用户
一句话说明："已将本次任务经验写入 D:\经验库\xxx.md"

## 强制性行为规则

| 规则 | 说明 |
|------|------|
| **阶段一、二为任务前强制** | 每次用户给任务，必须先检查经验库和 prompt 模板，再执行 |
| **阶段四为任务后强制** | 每次任务完成，必须整理产出物到 outbox/，不允许留在根目录 |
| **阶段五在触发条件下强制** | 复杂任务完成后必须写经验，不允许跳过的理由："太简单"不成立 |
| **原始文件不删不覆盖** | 只读取 inbox/ 中的文件，不修改、不移动、不删除原始文件 |
| **outbox 只放草稿** | 检查完成的任务提醒用户移入 archive/，outbox 保持干净 |
| **文件名带日期版本号** | 自动使用 `YYYY-MM-DD-任务名-v1` 格式，禁止使用模糊命名 |
| **一次只做一个任务** | 用户同时说多个任务时，按顺序逐个处理，不合并指令 |
| **结果必须人工验收** | 标注"待人工确认"标记，尤其是事实、数据、金额、负责人、截止时间 |
| **敏感数据提醒** | 如涉及员工信息、合同金额、客户隐私，提醒用户先脱敏 |

## 项目长期记忆联动

**每次执行任务前自动检查项目 MEMORY.md：**
1. 读取 `D:\工作空间\{项目}\.workbuddy\memory\MEMORY.md`
2. 关注其中的 `工作空间文件组织规范` 和 `产出物存放规则` 部分
3. 严格按照记忆中的规则执行文件整理

**任务完成后：**
1. 如果修改了规则或新增偏好，更新 MEMORY.md
2. 不要覆盖已有内容，在文件末尾追加新规则
