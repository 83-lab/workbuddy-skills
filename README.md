# WorkBuddy Skills 🛠️

博柯莱出品的 WorkBuddy 自定义技能合集。

## 技能列表

| 技能 | 说明 |
|------|------|
| [zh-desc-filler](zh-desc-filler/) | 自动为已安装的 skill 补上中文描述（description_zh） |
| [json-prompting](json-prompting/) | JSON 提示词生成器：自然语言描述需求 → 结构化 JSON 提示词 |
| [mou-er-hou-dong](mou-er-hou-dong/) | 谋而后动：复杂任务设计优先审核流程 |
| [project-workspace-init](project-workspace-init/) | 项目工作空间初始化，自动创建 inbox/outbox/archive 目录结构 |
| [skill-factory](skill-factory/) | Skill 工厂：从任务描述零生产高质量 Skill |

## 安装方式

### 方式一：Git 仓库导入（推荐）
复制本仓库 HTTPS 链接，在 WorkBuddy 中：
头像 → Claw 设置 → 技能管理 → 从 Git 仓库导入 → 粘贴地址

### 方式二：手动导入
1. 下载此仓库的 zip 包
2. WorkBuddy → Claw 设置 → 技能管理 → 导入技能 → 选择 zip
